# Autogram macOS v0.4.0

Podpis mobilom, Safari rozšírenie, rozšírené bezpečnostné prvky ZaKo a nové natívne rozhranie.

## Čo je nové

- **Podpis mobilom:** QR kód pre Autogram v mobile a NFC eID na iPhone. Podporuje bežné podpisovanie aj ZaKo, kde aplikácia vyžaduje mandátny certifikát.
- **Safari rozšírenie:** podpisovanie PDF a elektronických formulárov na podporovaných štátnych portáloch. Každá požiadavka vyžaduje potvrdenie v samostatnom okne, kartou alebo mobilom. Rozšírenie komunikuje natívne, bez otvoreného HTTP portu, a umožňuje návrat k pôvodnému podpisovaču portálu.
- **Nové UI:** postup v podnadpise okna, skryteľný inšpektor s nastaviteľnou šírkou, priehľadné pozadie vizuálneho podpisu, natívne vyhľadávanie a lepšie ovládanie klávesnicou. Reset dokumentu je počas podpisovania zablokovaný.
- **ZaKo:** 16 druhov bezpečnostných prvkov vrátane šnúrky/trikolóry, pásky a pečate. Fyzická kontrola originálu umožňuje textový záznam bez umelého rámca v skene. Dokument bez prvkov vyžaduje výslovné potvrdenie po kontrole strán.
- **AI Vision a učenie:** lokálna banka potvrdených a odmietnutých výrezov, osobitná evidencia kompletne skontrolovaných strán a export pre Create ML s rozdelením podľa celých dokumentov. Export sám model nenatrénuje; presnosť nových tried vyžaduje meranie na samostatných skenoch.
- **PDF/A a dokumentácia:** opravená normalizácia PDF/A v pribalenom Java engine, aktualizovaný README a čitateľnejšie diagramy vrátane AI Vision.

## Požiadavky

- Apple Silicon (arm64), macOS 27 alebo novší. Toto vydanie neobsahuje Intel build.
- Apple Intelligence je voliteľná a zapína vstavanú modelovú klasifikáciu neistých nálezov.
- Pri podpisovaní kartou treba príslušný PKCS#11 ovládač, napríklad eID klient alebo I.CA SecureStore. Podpis mobilom vyžaduje Autogram v mobile a podporovaný NFC eID.
- Java engine, runtime a Finder Quick Action sú v aplikácii. Samostatnú Javu netreba inštalovať.

## Inštalácia

1. Otvorte `Autogram-macOS-v0.4.0.dmg` a presuňte `Autogram macOS.app` do **Applications**.
2. Aplikácia je podpísaná lokálne (ad hoc), bez Apple Developer ID a notarizácie. Ak macOS spustenie zablokuje, potvrďte **Hotovo** a povoľte aplikáciu cez **Systémové nastavenia > Súkromie a bezpečnosť > Aj tak otvoriť**.
3. Spustite aplikáciu z priečinka Applications.

### Voliteľné podpisovanie zo Safari

Po nainštalovaní aplikácie spustite `Install Safari Bridge.command` z DMG. Skript zaregistruje používateľský launchd agent smerujúci na `/Applications/Autogram macOS.app`. Prípadné blokovanie stiahnutého skriptu riešte cez rovnaké nastavenie **Aj tak otvoriť**.

V Safari povoľte funkcie pre vývojárov, potom **Develop > Allow Unsigned Extensions** a rozšírenie **Autogram na štátnych weboch** v **Settings > Extensions**. Safari povolenie nepodpísaných rozšírení po reštarte zabudne. Bez tohto nastavenia Safari toto vývojové rozšírenie nenačíta.

## Stav ZaKo a overenia

Formulárový balík zostáva pilotný. Produkčné zapojenie EZZK/CEZZK čaká na potvrdenie integračných podkladov; aplikácia ho neobchádza. Overenie sekcie bezpečnostných prvkov record 1.0 nepotvrdzuje súlad celého formulára. AI navrhuje nálezy, právne posúdenie robí človek.

## Overenie zostavy

- Swift: 405 testov, z toho 400 úspešných a 5 preskočených testov vyžadujúcich osobitné lokálne vstupy alebo integrácie.
- Java: 169 vybraných testov normalizácie PDF/A, podpisových parametrov a strojového protokolu, bez zlyhaní.
- Produkčný Swift build a zostavenie pribaleného Java engine vrátane kontroly `CAPABILITIES`.
- Kontrola podpisu aplikácie, obsahu DMG a SHA-256. Podpis fyzickou kartou, mobilom a produkčné EZZK neboli pri tomto vydaní nanovo overené end-to-end.

## Kontrolný súčet

Pri DMG je zverejnený súbor `SHA256SUMS.txt`. Po stiahnutí oboch súborov do rovnakého priečinka overte obraz príkazom:

```bash
shasum -a 256 -c SHA256SUMS.txt
```
